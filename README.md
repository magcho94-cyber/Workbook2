# 종로M ENGLISH TEST STUDIO + READING WORKBOOK

기존 WEEKLY TEST, SIMUL TEST, VOCA 기능에 **READING WORKBOOK** 탭을 추가한 Node/Express 앱입니다. 브라우저에서 문단별 진행률을 확인하고 학생용·교사용을 각각 PDF로 인쇄합니다.

## 실행

```bash
npm install
export OPENAI_API_KEY="본인의_API_키"
npm start
```

브라우저에서 `http://localhost:3000`으로 접속합니다. Render에서는 저장소의 루트에 이 폴더 내용을 올리고, **Build Command**를 `npm install`, **Start Command**를 `npm start`로 설정하세요. 환경변수 `OPENAI_API_KEY`가 필요합니다. 기존 시험 출제 이력을 영구 보관하려면 `DATABASE_URL`을 선택적으로 설정할 수 있습니다.

선택 환경변수: `OPENAI_MODEL`(기존 시험 생성), `OPENAI_WORKBOOK_MODEL`(워크북 문장 분석, 기본값 `gpt-5-mini`), `OPENAI_IMAGE_MODEL`(삽화, 기본값 `gpt-image-1-mini`). 이미지는 `1024×1024`, `low` 품질로 요청합니다.

## 워크북 사용

1. **READING WORKBOOK** 탭에 제목과 영어 본문을 붙여넣거나 PDF/DOCX/TXT/MD 파일을 올립니다. 빈 줄로 문단을 나누고, 문단 소제목은 `# 소제목`으로 입력합니다. 영어 문장마다 줄바꿈할 필요는 없습니다. 번호가 붙은 줄은 번호를 제거합니다.
2. 우리말 해석이 있으면 같은 문단과 문장 순서로 붙여넣습니다. 비워 두면 자동 작성합니다. 해석 문장 수가 맞지 않으면 오류가 표시됩니다.
3. **워크북 생성**을 누릅니다. 문단 분석은 최대 3개, READING 삽화는 최대 4개를 동시에 처리하며, 완성된 문단의 삽화는 다른 문단을 분석하는 동안 시작합니다. 글이 먼저 미리보기에 나오고, 삽화가 뒤이어 채워집니다. 삽화가 일부 실패하면 **삽화 재시도**를 누릅니다.
4. 완성 후 **학생용 PDF 저장**, **교사용 PDF 저장** 버튼에서 브라우저의 인쇄 대상 **PDF로 저장**을 선택합니다. 각 버튼은 해당 부분만 인쇄합니다. 브라우저 인쇄 옵션에서 A4와 배경 그래픽을 사용하면 원래 디자인에 가깝습니다.

워크북 구성: READING은 **페이지마다 원문 2~3문장과 그 문장에 맞춘 삽화**, 문장·해석, 문단 끝의 주제·제목 칸입니다. STEP 1은 모든 문장의 해석·문장 사이 논리 관계 빈칸·내용확인·한글 O/X, STEP 2는 각 문장 빈칸 2~3개, STEP 3은 각 문장 어법 선택과 근거 2줄, STEP 4는 문단 나열, STEP 5는 문장 나열입니다. 교사용에는 정답과 문장 연결 설명을 넣습니다. 삽화는 READING에만 배치합니다.

작업 결과와 삽화는 서버 메모리에 임시 보관되므로 서버 재시작 후에는 다시 생성해야 합니다. 출력 전에 내용과 생성 삽화를 검토하세요. `초안 JSON` 버튼으로 문장별 초안을 내려받을 수 있습니다. API 사용량은 입력 문단과 삽화 장수에 따라 달라집니다.

## 확인

```bash
npm test
```

문장 보존, 2~3문장 READING 묶음, 빈칸/어법 유효성, API 작업의 단계별 진행, 학생용 단계·삽화 위치를 확인합니다.
